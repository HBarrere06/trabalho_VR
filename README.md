# Projeto VR — Jogo de Realidade Virtual

## Descrição do Projeto

Este projeto consiste no desenvolvimento de um jogo em **Realidade Virtual (VR)** utilizando a Unity. O objetivo é proporcionar uma experiência interativa na qual o jogador explora um ambiente virtual, interage com objetos e realiza tarefas para avançar na experiência.

O jogo possui um sistema de alternância entre dia e noite, interação e posicionamento de objetos, coleta de itens e progressão por meio de uma porta que é liberada após a coleta de todos os objetos necessários.

A aplicação utiliza recursos de realidade virtual para permitir que o jogador interaja com o cenário por meio dos controles, utilizando mecanismos de seleção, interação por raio e manipulação de objetos.

## Tecnologias, Linguagens e Bibliotecas

| Tecnologia | Utilização |
|---|---|
| Unity | Desenvolvimento do ambiente e da aplicação VR. |
| C# | Linguagem utilizada na programação dos sistemas e interações. |
| Meta XR Simulator | Simulação e testes da experiência de realidade virtual. |
| XR Interaction Toolkit (XRI) | Implementação de interações, seleção e manipulação de objetos VR. |
| Unity UI | Criação de interfaces, imagens e elementos visuais. |
| Unity Physics | Detecção de colisões, áreas de interação e posicionamento de objetos. |

## Execução do projeto

Para executar o projeto basta clonar o código do github, abrir o projeto no unity e apertar **Play** no editor.
Para isso, são necessários:

- Unity Hub.
- Unity Editor, utilizando a mesma versão do projeto.
- Pacote XR Interaction Toolkit.
- Pacote XR Plug-in Management.
- Meta XR Simulator.
